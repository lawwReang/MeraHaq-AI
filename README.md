# MeraHaq AI 🇮🇳

MeraHaq AI is an intelligent, AI-powered assistant designed to help Indian citizens effortlessly discover and apply for government schemes, grants, and benefits tailored to their unique profiles.

## ✨ Features

- **Personalized Recommendations**: Get scheme suggestions curated specifically for your profile (Age, Gender, Category, Income, State, and Occupation).
- **Smart Conversational AI**: Interact with a Gemini AI-powered assistant to explore "What if" scenarios, ask specific eligibility questions, and find the right benefits.
- **Actionable Application Guides**: Receive detailed, step-by-step roadmaps on how to apply for specific schemes, including required documents, expert tips, and official portal links.
- **Secure User Profiles**: Save your profile demographics and bookmark your favorite schemes to access them later, powered by Firebase.
- **Modern & Responsive UI**: A beautiful, accessible, mobile-first interface built with React, Tailwind CSS, and smooth animations using Framer Motion.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Framer Motion, Lucide React
- **Backend & Database**: Firebase (Authentication and Firestore)
- **AI Engine**: Google Gemini 2.5 Flash via the `@google/genai` SDK

## 🚀 Getting Started

1. Clone the repository.
2. Install dependencies by running `npm install`.
3. Set up your Firebase project and add your configuration to `firebase-applet-config.json`.
4. Ensure your Gemini API key is configured.
5. Start the development server with `npm run dev` or `npm start`.

## 🛡️ Privacy & Security
User data is securely handled using Firebase Authentication and Firestore Security Rules to ensure that profile information and saved schemes remain private and protected.
